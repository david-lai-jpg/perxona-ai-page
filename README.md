# David Lai｜醫療軟體與診所管理系統開發

David Lai 賴大衛的繁體中文個人網站，採用 Bold Editorial 視覺系統。

## 本機預覽

直接開啟 `index.html`，或執行：

```bash
python3 -m http.server 8000
```

網站網址：<https://david-lai-jpg.github.io/perxona-ai-page/>

## 部署

GitHub Pages 從 `main` 分支根目錄發布。推送至 `main` 後，GitHub 會自動更新網站。

## Perxona

Perxona Avatar 已使用官方 Web Embed Code 嵌入。部署金鑰只允許從 `david-lai-jpg.github.io` origin 使用；其他 API Key、Token 或憑證不得寫入此儲存庫。
